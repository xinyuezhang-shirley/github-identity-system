# Information architectures

Section-by-section outlines for the three directions with a real path to
a first artifact within a static file's constraints (no runtime). Field
Notes and Topology remain live options once this project builds past a
GitHub README into something with a server or a canvas that persists.

## Field Notes IA — pairs with Direction A

| | Section | What it holds |
|---|---|---|
| I | Specimen header | Name set as a field-tag, coordinates-style meta line (location, current focus, date), no photo |
| II | Current investigations | 2–3 dated one-liners — what's actually being looked at right now, not a mission statement |
| III | Field observations | Repos as ledger rows, each a dated observation, not a card |
| IV | Signal trace | Commit rhythm — see `prototypes/instrument/` |
| V | Language topology | See `prototypes/topology/` |
| VI | Open questions | 2–3 honest unresolved things — the brief's "unfinished instrument" feeling, made literal |
| VII | Footnotes | Contact, license-style colophon, no icons |

## Instrument IA — pairs with Direction B, built in `prototypes/instrument/`

| | Section | What it holds |
|---|---|---|
| I | Calibration header | Name + a reading-style meta line, framed as an instrument's nameplate |
| II | Live readout block | Commit signal trace as the dominant, largest element on the page |
| III | Selected work | MuseLab and Echo only, each given real space — not six repos at equal weight |
| IV | Topology gauge | Language field, framed as a secondary dial next to the main trace |
| V | Archive | Everything else, collapsed into a single `<details>` ledger, deliberately de-emphasized |
| VI | Footnotes | Stack, fonts, last-calibrated date |

## Folio IA — pairs with Direction C, built in `prototypes/folio/`

| | Section | What it holds |
|---|---|---|
| I | Dossier masthead | "No. —" numbering, role line, hairline rule |
| II | Index | I, II, III… numbered entries — projects and standing research interests interleaved, not just repos |
| III | Selected folio spread | 1–2 projects expanded with a real diagram each |
| IV | Colophon | Stack, fonts, "printed/updated" date, license note — styled like Echo's `compose-frame__footer` |

---

Two directions don't have a dedicated IA above but do have prototypes:
**Topology** (`prototypes/topology/`) is closer to a single full-bleed
diagram than a multi-section document, so its "architecture" is really
just the diagram plus a caption line. **Ledger** (`prototypes/ledger/`)
is a single dense table — its architecture *is* the table's column order.
