# Mockups

Static exports of the diagrams described in
[design-dna.md](../design-dna.md), for reading without spinning up a
server. The live, theme-reactive versions are the actual prototypes under
`prototypes/` — these SVGs are the paper trail, not the deliverable.

All four are generated by `scripts/build_diagrams.py` from
`assets/generated/*.json` — regenerate after `scripts/fetch_github_data.py`
to keep them current.

### Language topology

Real aggregated language byte share across non-fork repositories, placed
on a polar field where radius is inverse to share (Strand 04,
Mathematical DNA). One repository's vendored dependency blob is excluded
— see the `exclusion_reason` field in `assets/generated/languages.json`.

![Language topology](../../assets/diagrams/language-topology.svg)

Live version: [`prototypes/topology/`](../../prototypes/topology/)

### Commit signal trace

The real 53-week contribution calendar, drawn straight — no smoothing, no
manufactured streak.

![Commit signal trace](../../assets/diagrams/commit-signal-trace.svg)

Live version: [`prototypes/instrument/`](../../prototypes/instrument/)

### Mathematical spiral proof

Not real data — a 26-point demonstration of `vortex.js`'s own placement
formula (`angle = index × 0.42`), included so the formula in
design-dna.md isn't just prose.

![Mathematical spiral proof](../../assets/diagrams/mathematical-spiral-proof.svg)

### Motion settle curve

The literal 60-frame iteration of `value += (target − value) × k` at
k = 0.14 — monotonic, no bounce, no invented oscillation.

![Motion settle curve](../../assets/diagrams/motion-settle-curve.svg)
